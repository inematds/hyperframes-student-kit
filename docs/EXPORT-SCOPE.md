# Escopo da exportação

A parte do pipeline foi montada originalmente a partir de uma lista de permissão de
skills reutilizáveis, scripts auxiliares, fontes da biblioteca e fontes de templates
com histórico público novo. Esta atualização mescla esse histórico público no student
kit público existente; ela não importa o histórico Git do workspace privado de produção.

A nova skill de short-form inclui suas instruções, uma planilha de referência
generalizada e validadores. Nomes de arquivo de vídeos de referência pessoais e a
análise privada de gravações foram substituídos por uma planilha reutilizável. Os dados
de teste sintéticos foram criados separadamente. Nenhuma gravação privada, transcript,
decisão de edição, credencial ou configuração específica de máquina foi adicionada.

Os exemplos de vídeo já públicos do repositório original e os assets compartilhados de
marca permanecem inalterados. Este repositório combinado, portanto, inclui a mídia
existente; não é uma exportação sem mídia. Novas mídias e projetos de alunos são gitignored.
